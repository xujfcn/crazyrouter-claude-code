Get started

Pick the path that matches you

Not sure if Claude Code is installed? Run claude --version. A version number means use Configure; "command not found" means Full install.

Recommended

Configure only

Claude Code already installed — just point it at Crazyrouter. Seconds, no reinstall.

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/xujfcn/crazyrouter-claude-code/main/configure.sh | bash
# Windows PowerShell
irm https://raw.githubusercontent.com/xujfcn/crazyrouter-claude-code/main/windows/configure.ps1 | iex

Full install

Claude Code not installed yet. Installs Git, Node.js, Claude Code, then configures Crazyrouter.

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/xujfcn/crazyrouter-claude-code/main/setup.sh | bash
# Windows PowerShell
irm https://raw.githubusercontent.com/xujfcn/crazyrouter-claude-code/main/windows/setup.ps1 | iex

Get a token first at cn.crazyrouter.com

How it works

Three steps, then you are coding

01

Run the command

Paste the one-liner. The script asks for your token, base URL, and default model — press Enter for defaults.

02

Open a new window

Environment variables apply to new shells. Open a fresh terminal, or source the env file on macOS/Linux.

03

Run claude

Claude Code starts and routes every request through Crazyrouter. That's it.

Under the hood

What the script writes

Six user-level environment variables. Both Anthropic and OpenAI styles are set, so one token works across Claude Code and other OpenAI-compatible tools.

ANTHROPIC_BASE_URL
https://cn.crazyrouter.com
ANTHROPIC_AUTH_TOKEN
<your token>
ANTHROPIC_MODEL
claude-opus-4-8
CLAUDE_MODEL
claude-opus-4-8
OPENAI_API_KEY
<your token>
OPENAI_BASE_URL
https://cn.crazyrouter.com/v1
